SLEEPYCHAT 1.0.0 — RELEASE NOTES
================================
Made by SleepyKev • 2026

SleepyChat 1.0.0 is the standalone Windows desktop release for unified Kick
and Twitch chat.

HIGHLIGHTS
==========
- Unified All / Kick / Twitch / Mentions chat views.
- Hosted Connect with Kick OAuth flow with Kick chat receiving and sending.
- Twitch read-only chat by channel.
- Twitch/Kick badges and 7TV support.
- Search, role filters, mention highlighting, density controls, and export.
- GitHub Releases update checker.
- Custom borderless Windows shell with tray support and edge/corner resizing.

BRANDING / THEMES
=================
- Midnight Pulse uses the supplied blue/cyan raccoon logo.
- Crimson Rush uses the supplied red raccoon logo.
- Violet Void uses the supplied purple raccoon logo.
- Toxic Glow uses the supplied green raccoon logo.
- Bubblegum Byte uses the supplied pink raccoon logo.
- Theme switching updates the top-left SleepyChat logo automatically.

WINDOW ICON FIXES
=================
- Corrected the SleepyChat Windows application icon framing.
- Multi-resolution app.ico includes 16, 32, 48, 64, and 128 pixel frames.
- The application icon is used for the EXE, taskbar, Alt+Tab, title bar,
  tray icon, and shortcuts.

PACKAGING
=========
- Windows x64 self-contained application.
- No installer is required; extract the Public ZIP and run SleepyChat.exe.
- Runtime data is kept in SleepyChat_Data beside the application.
- Public product version remains SleepyChat 1.0.0.
