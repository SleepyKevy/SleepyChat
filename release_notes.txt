CODE AUDIT / SOURCE STRUCTURE CLEANUP
=====================================
- Reorganized the C# source into focused App, Backend, Kick, Updates, and Window folders.
- Split the oversized MainForm, HostedKickService, and BackendHost responsibilities into smaller partial files.
- Extracted the WebView CSS and JavaScript from the old monolithic index.html into web/css and web/js.
- Removed stale bundled Cloudflare Worker/deployment material from the SleepyChat source package.
- Removed obsolete validation/build assumptions and updated the build script for the current shared Kick API.
- Removed unused duplicate assets from the cleaned source tree.
- Added architecture, shared-backend, and code-audit documentation.
- Runtime behavior and the public product version remain SleepyChat 1.0.0.

EDGE / THEME RENDER FIX
=======================
- Removed the transparent WinForms resize panels that were sitting over the outside edge of the WebView.
- Those panels exposed the form background and caused the black square/frame effect on non-blue themes.
- Manual resizing now uses logic-only edge and corner hit detection; nothing visual is layered over the themed UI.
- Disabled Windows DWM outer-window corner rounding to remove clipped/jagged pixels around the borderless window corners.
- The fix applies to every SleepyChat theme because the resize system no longer draws over the web UI at all.

MANUAL WINDOW RESIZING
======================
- Drag the left, right, top, or bottom edge to resize.
- Drag any corner to resize width and height together.
- Normal resize cursors remain available.
- Minimum window size remains 980 x 680.
- Resize handling disables while maximized.
- No native Windows caption/frame was restored.

UPDATE CHECKER

- The connection-style Updates card remains directly under Kick and Twitch.
- Status light states remain blue/checking, green/up to date, amber/update available, and red/check failed.
- Check Now and GitHub controls remain included.
